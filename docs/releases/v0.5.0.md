# v0.5.0 · Phase 4: policy search

Hybrid, reranked search over the policy conditions, with local models chosen by measurement.

## Included

- **Policy search** (`tramita_agents.search`): one clause per entry, always within the policy's
  product. BM25 in OpenSearch with a Spanish, accent-folding analyzer; local embeddings
  (`jinaai/jina-embeddings-v2-base-es`) in pgvector, in the agent service's own schema;
  reciprocal rank fusion of ten candidates per stage; a local cross-encoder
  (`BAAI/bge-reranker-v2-m3`, int8). Models run on CPU through fastembed: no API key, no PyTorch.
- **Privacy and traceability**: queries are masked like documents before any backend or model;
  each hit keeps its lexical, vector and fused rank and its rerank score. A missing or stale
  index is refused with the command that fixes it.
- **`make index`**, **`make eval-retrieval`** and **`POST /policy-search`** on the agent service.
- **Evaluation** on 432 queries: 72 claim descriptions answered by the clause that grounds the
  expected decision, 295 everyday questions, 65 keyword searches. Hit@5:

  | Query set | BM25 | Vectors | Hybrid + reranker |
  |---|---|---|---|
  | Claims | 51.4% | 87.5% | 91.7% |
  | Questions | 53.9% | 95.6% | 90.2% |
  | Keyword searches | 100% | 72.3% | 100% |
  | All | 60.4% | 90.7% | 91.9% (hit@1 73.6%) |

- **Model choice with numbers** (ADR 0012): four embedding models, two rerankers and two
  candidate counts compared; ten candidates halve the reranking time with the same hit@5.
- **CI** indexes the conditions and gates hit@5 per mode and query set; models are cached.
- **Verification**: 174 Python tests, 41 Java. Endpoint checked against the running stack.

## Known limitations

- The queries are synthetic and written by the project's author: the numbers compare options,
  they do not predict accuracy on real policyholder text.
- Reranking takes about 1.5 s per query on a desktop CPU.
- ONNX scores vary slightly across CPUs (one query of 137 between two CI runners).
- About 1.2 GB of models are downloaded on first use.
