# v0.1.0 · Phase 0: foundations

The repository, tooling and local infrastructure every later phase builds on.

## Included

- **Services**: FastAPI agent service skeleton (Python 3.12, uv workspace, strict mypy, ruff) that
  selects a deterministic fake model when no API key is set; Spring Boot 3.5 core service skeleton
  (Java 17) with actuator health and Spotless formatting.
- **Local stack** (`make up`), every service with a health check: PostgreSQL 17 + pgvector,
  Kafka 4.2 in KRaft mode, OpenSearch 3.9, RustFS (S3-compatible), Temporal 1.29 and its UI.
- **Security**: gitleaks pre-commit hook and full-history scan in CI; `.env.example` with
  local-only placeholders.
- **CI**: secret scan, Python lint/types/tests, Java build/tests and a compose smoke test on every
  push. Failing steps publish their output as annotations. Releases are created from
  `docs/releases/*.md`.
- **Decisions**: ADRs 0001 to 0006, including why MinIO was replaced by RustFS.
